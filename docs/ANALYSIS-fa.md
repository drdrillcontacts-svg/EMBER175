# تحلیل پلاگین EMBER 175-B

این سند خلاصهٔ فارسی بررسی نسخهٔ قبلی، معماری جدید و نتایج اندازه‌گیری است.

## ۱) بررسی نسخهٔ قبلی (چه چیزی درست نبود)

| مورد | وضعیت قبلی | مشکل |
| --- | --- | --- |
| نسبت کمپرس | `ratio = 12` ثابت، روی یک envelope سادهٔ feed-forward | ۱۲:۱ فقط عدد بود؛ رفتار واقعی ۱۷۵-B «در آستانه ۱۲:۱، و بالاتر از آستانه سخت‌تر» است |
| دیتکتور | peak follower با ضریب ثابت + گین جداگانه با attack/release دیگر | حلقهٔ فیدبک (که امضای صوتی ۱۷۵-B است) وجود نداشت؛ دو مرحلهٔ مستقل باعث پامپ و رفتار غیرقابل پیش‌بینی می‌شد |
| Attack / Release | 0.1–100 ms و 5–2000 ms | خارج از مشخصات سخت‌افزار (۱۰۰ میکروثانیه تا ۱ میلی‌ثانیه، و ۲۷ تا ۵۲۷ میلی‌ثانیه) و بدون حالت `OFF` |
| Input / Output | -24 تا +24 dB پیوسته | روی دستگاه، اتنوئیتور ۰ تا ۴۰ dB در پله‌های ۲ dB + ورنیه ±۲ dB است |
| Threshold | یک ناب مستقل | در ۱۷۵-B «threshold» همان INPUT است؛ نابِ جداگانه رفتار دستگاه را عوض می‌کند |
| اشباع لامپ | `tanh(x*drive)/tanh(drive)` | این فرمول بهرهٔ سیگنال کوچک را هم تغییر می‌دهد (≈ drive)، پس با تغییر رنگ، سطح هم می‌پرید؛ نه ترانس، نه بایاس متغیر |
| اورسمپلینگ | نداشت | هارمونیک‌های بالا alias می‌شدند (در تست، هارمونیک تاشده تا -۱۹ dB دیده می‌شد) |
| Latency | صفر اعلام می‌شد | با اورسمپلینگ باید گزارش شود، وگرنه DAW جبران نمی‌کند |
| Stereo link | پارامتر وجود داشت ولی در DSP استفاده نمی‌شد | لینک استریو عملاً کار نمی‌کرد |
| Bypass | `return` قبل از پردازش | کلیک هنگام سوییچ، و بی‌توجه به تأخیر مسیر پردازش‌شده |
| UI | هشت اسلایدر گرد + دو چک‌باکس | شبیه پنل سخت‌افزار نبود |

## ۲) مدل جدید

مسیر سیگنال مطابق توضیحات عمومی مدار ۱۷۵-B:

```
input ──► اتنوئیتور ورودی ──► ترانس ورودی ──► 6BC8 (vari-mu) ──► 12AX7/12BH7 ──► ترانس خروجی ──► اتنوئیتور خروجی ──► out
                                                   ▲                    │
                                                   │  شبکهٔ attack/release│
                                                   └── رکتیفایر 6AL5 ◄──┘
```

* **حلقهٔ فیدبک بسته**: دیتکتور از همان نقطه‌ای سیگنال می‌گیرد که وارد عنصر بهره می‌شود؛ به همین دلیل «نرم در سطح پایین، دیوار در سطح بالا» به‌صورت طبیعی بیرون می‌آید.
* **قانون بهره**: `GR = u · (1 − 1/R(u))` با `R(u) = 12 + 0.4·u` → در آستانه ۱۲:۱، در +۱۰ dB حدود ۱۶:۱ و در +۲۰ dB بالای ۳۰:۱.
* **بالستیک**: دو خازن (سریع/کند) در دامنهٔ dB، دقیقاً مثل یک CV آنالوگ؛ نتیجه: attack اندازه‌گیری‌شده ۰٫۱۰ تا ۱٫۰ میلی‌ثانیه و release ۲۷ تا ۵۲۷ میلی‌ثانیه با تیل برنامه‌محور.
* **غیرخطی‌ها**: ترانس ورودی (اشباع هستهٔ LF + عدم تقارن مرتبهٔ دوم)، انحنای گرید 6BC8، افزایش اعوجاج با افزایش بایاس (هرچه GR بیشتر، درایو بیشتر)، مرحلهٔ 12AX7/12BH7 و ترانس خروجی.
* **۴ برابر اورسمپلینگ** (۲ برابر برای نرخ‌های بالای ۱۲۰ کیلوهرتز) با فیلتر نیم‌باند ۶۳ تپ؛ بدترین هارمونیک تاشده در ۱۱ کیلوهرتز زیر −۹۵ dB و تأخیر ثابت ۴۶ سمپل که به هاست گزارش می‌شود.

## ۳) نتایج اندازه‌گیری (تست‌ها)

| کمیت | مقدار |
| --- | --- |
| نسبت در آستانه | ≈ ۱۲:۱ (اندازه‌گیری ۱۰ تا ۱۶:۱ روی پله‌های ۲ dB) |
| نسبت در درایو بالا | ۲۰ تا ۱۰۰:۱ (بسته به سطح) |
| Attack | ۰٫۱۹ ms در تنظیم ۰٫۱ ms — ۰٫۹۸ ms در تنظیم ۱ ms |
| Release | ۲۹ ms در تنظیم ۲۷ ms — ۵۵۵ ms در تنظیم ۵۲۷ ms |
| بهرهٔ واحد زیر آستانه | ±۰٫۰۲ dB |
| پاسخ فرکانسی | −۰٫۵ dB در ۶۰ Hz (افت طبیعی ترانس)، صاف تا ۲۰ kHz |
| THD | ۰٫۲٪ در بهرهٔ واحد، ۱٪ در GR≈۶ dB، ۳٪ در GR≈۹ dB |
| Aliasing | زیر −۹۵ dB |
| سرعت | ≈ ۲۹ برابر realtime روی یک هسته (استریو، ۴۸ کیلوهرتز) |

## ۴) ظاهر

پنل کامل با کد کشیده می‌شود (`Source/UI/PanelRenderer.cpp`) و از نمایشگر مستقل بیرون از DAW هم قابل رندر است:

* گوش‌های فلزی برس‌خورده با سوراخ رک و پیچ‌ها
* کانکتورهای XLR ورودی/خروجی
* صفحهٔ تیرهٔ اکسیدشده با لکه، خش و وینیت
* پلاک برنجی `EMBER / LIMITING AMPLIFIER NO. 175-B`
* نوب‌های باکلیت شیاردار با حلقهٔ مدرج چاپی (۰ تا ۴۰ در پله‌های ۲ dB)
* ولت‌متر کرم دو مقیاسه (VU و GR) زیر شیشه، با سوزن و بالستیک مکانیکی
* کلید برق اهرمی + LED، و نوار «EXTENDED CONTROLS» پایین برای پارامترهای نرم‌افزاری

## ۵) ساخت VST3 با گیت‌هاب اکشن

`Actions → Build VST3 → آخرین اجرا → Artifacts`

| خروجی | توضیح |
| --- | --- |
| `EMBER175-B-Windows-x64-VST3.zip` | پوشهٔ `.vst3` آمادهٔ کپی در `C:\Program Files\Common Files\VST3` |
| `EMBER175-B-macOS-universal.zip` | `.vst3` + `.component` یونیورسال (arm64 + x86_64) |
| `EMBER175-B-Linux-x64.zip` | `.vst3` آمادهٔ `~/.vst3` |
| `EMBER175-B-front-panel` | رندر PNG از پنل |

ساخت محلی:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/ember_dsp_tests -v
```

## ۶) محدودیت‌ها و نکات حقوقی

* این یک مدل رفتاریِ فیزیک‌محور است، نه شبیه‌سازی SPICE یا کپچرِ یک دستگاه مشخص.
